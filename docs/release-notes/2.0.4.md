Notarized Developer ID build for macOS 26 or newer. Unzip, then drag Pallet.app to Applications (replace the old one).

Fixes in 2.0.4 (the 20 October code review)
- **Never "Saved" when it wasn't:** while Pallet can't read your collection file, a new or changed palette says "Not saved", in the window and in the menu bar panel.
- **A sync can finish first:** at launch, a collection file that a sync tool is still writing gets about 2 seconds before Pallet calls it unreadable.
- **A sync's changes stay:** if another Mac changed your collection while Pallet was open, the next save reads it again first instead of writing over it.
- **Safe shortcuts:** the capture and panel shortcuts can't take keys every app needs, like Command-Q, Command-C or Command-V.
- **A removed shortcut stays removed** after you quit and reopen Pallet.
- **Undo from the menu bar:** a palette saved from the panel can be undone there, even before the window has opened.
- **Dock only:** a missing Screen Recording permission or a failed capture now shows a message.
- **Smaller fixes:** recording a menu shortcut no longer starts a capture; Restore Defaults also resets the two global shortcuts; an unreadable file is copied aside once, not at every launch.
- **Web:** importing a collection keeps the palettes it can read; a heart on one of Kika's palettes no longer freezes an old copy of it.
