# Pallet for Mac

Build Pallet.app on this Mac. The app is unsigned.

See **[docs/mac.md](docs/mac.md)** for the full steps.

Short path:

1. Install Node.js 24 LTS from https://nodejs.org.
2. Double-click **Setup Mac.command**.
3. Move **Pallet.app** into Applications. Control-click → Open if macOS blocks it.

Data: `~/Library/Application Support/Palette/`.
